# Portfolio

This is my personal frontend developer portfolio.

The portfolio presents my projects, skills, and information about me as a frontend developer. It was developed with a focus on responsive design, clean code, and a modern user experience.

## Technologies

This project was built using:

- HTML
- CSS
- JavaScript
- PHP
- JSON

## Features

- Responsive design for desktop, tablet, and mobile devices
- German and English language support
- Interactive project showcase
- Project detail overlays
- Animated UI elements
- Testimonials carousel
- Contact form
- Responsive mobile navigation
- Custom animations and hover effects
